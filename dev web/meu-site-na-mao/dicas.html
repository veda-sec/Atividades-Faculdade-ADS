Dicas rápidas

  • Nomeie os arquivos sem espaço, acento ou letra maiúscula — assim evita problema quando o site for publicado.
  • Separe o CSS do HTML desde o início, mesmo em um site pequeno. Fica mais fácil de mexer depois.
  • Use <h1>, <h2> etc na ordem certa, sem pular níveis só por causa do tamanho do texto.
  • Abra o site no celular de vez em quando, não só no computador.

Para consultar quando bater dúvida sobre alguma tag ou propriedade, a MDN é a referência mais confiável que existe sobre HTML e CSS.
