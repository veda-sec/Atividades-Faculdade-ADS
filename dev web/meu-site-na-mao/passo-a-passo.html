Como criar um site do zero

Não precisa de nada complicado para começar: um editor de texto (o Visual Studio Code é uma boa opção gratuita) e um navegador já bastam.

1. Crie uma pasta para o projeto

Dentro dela vai ficar tudo: o arquivo principal do site e, depois, os arquivos de estilo.

2. Escreva o HTML

Crie um arquivo chamado index.html com a estrutura básica de uma página:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Meu primeiro site</title>
</head>
<body>
  <h1>Olá, mundo!</h1>
  <p>Este é o meu primeiro site.</p>
</body>
</html>

Salve o arquivo e abra ele direto no navegador para ver o resultado.

3. Adicione um pouco de estilo

Crie um arquivo style.css na mesma pasta e conecte ele no HTML:

<link rel="stylesheet" href="style.css">

A partir daí, cores, fontes e espaçamento entram nesse arquivo, separado do conteúdo.

4. Teste e ajuste

Vá abrindo o arquivo no navegador conforme for mexendo no código. Redimensione a janela para ver como fica em telas menores.

5. Publique

Quando estiver satisfeito, é só subir os arquivos em algum serviço gratuito, como o GitHub Pages, para o site ficar acessível para qualquer pessoa.
